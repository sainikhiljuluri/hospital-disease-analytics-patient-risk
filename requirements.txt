# MODULE 5 - GENERATIVE AI  (scripts/05_generate_report.py)
# ===========================================================================
# NOTHING TO PIP INSTALL. The default AI provider is OLLAMA, running Llama
# locally on your own machine, and the project talks to it using Python's
# built-in urllib. No package, no API key, no account.
#
# Install Ollama itself (not a Python package) once:
#     1. https://ollama.com/download
#     2. ollama pull llama3.2
#
# Why local rather than a hosted API: patient records never leave the machine.
# For clinical data that is not a cost saving, it is the correct architecture.
#
# If Ollama is not installed, Module 5 still produces a complete report from a
# deterministic template using the identical grounded facts. That fallback
# demonstrates the architecture rather than apologising for it - if the report
# is right without an LLM, the grounding layer is doing the work.
